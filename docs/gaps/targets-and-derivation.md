### SG15 — bare-constant target families

- `state`: residual; D20/D21 additional target-policy calibration and literal profiles.
- `baseline`: [Repeatable constant owners](../implementation/repeatable-computations.md), [constant diagnostic ladder](../implementation/computations.md#cap-constant-assignment-diagnostic-ladder) and [field-copy comparisons](../implementation/computations.md#cap-field-copy-comparison) own the implemented carriers. Per-instance results and format-keyed temporal targets are not missing prerequisites.
- `diagnostics`: raw String versus Custom target refusal identity, addressed cross-kind copy classes, and category/partial-target refusal detail beyond the measured ladder and copy grid. Inspect the current carrier before extending a class projection; distinct source/target read failures cannot be conflated.
- `diagnostics`: wider joined operation/precondition parse and refusal ordering beyond the current Number/String alternative-admission matrices. [The source walk](../sources/inbound-handbacks.md#inbound-2026-09-26c-target-read) does not by itself establish every reader path.
- `remaining`: repeatable yearless-Date literal outcomes, common-Base-Year leap/precision/poison compositions and component-omitting target checks beyond the [Date constant boundary](../implementation/repeatable-computations.md#cap-repeatable-date-constant-computation).
- `remaining`: additional DateTime formats, overlap labels, over-capacity interactions and localized generated payloads beyond the [DateTime constant boundary](../implementation/repeatable-computations.md#cap-repeatable-datetime-constant-computation). Cross-kind target admission uses the shared format gate; a new carrier is not needed to repeat it.
- `evidence-needed`: starred-source over-limit behavior beyond the [row-extent capture](../sources/group-list-and-capacity-probes.md#src-repeatable-computation-row-extent); the seeded over-limit constant control does not calibrate every first-filled source.

The [DateRange source record](../sources/date-range-construction.md#src-date-range-fragment-first-filled) distinguishes literal-family classification from component mismatch; a refusal code alone does not prove that a literal was recognized.
- `reopen-when`: a consumer needs one named target policy or a current accepted-input discriminator fails. Scheduling remains [SG4](keystone.md#gap-sg4), application [SG16](keystone.md#gap-sg16).

### SG14 — mandatory-information derivation

- `state`: excluded service expansion; D13. This is rule-set analysis, not document validation or computation.
- `baseline`: [Flat mandatory information](../implementation/cross-clause.md#cap-flat-mandatory-information) owns recognized rule identities, the three derived sets, checked closure and retained evidence.
- `remaining`: other recognized rule families and count collector sites; longer, branching, seed-interleaved/reordered or reused count dependencies; and mixed-edge cycle calibration beyond the retained closure matrices.
- `remaining`: arbitrary Boolean formulas, wider repetition/parallel iteration, concrete and wider semantic indices, filter internals, and contributing cross-root forms. Exact excluded-rule identities must remain distinct from supported contributing shapes.
- `remaining`: declaration interactions beyond unconditional/direct field/root seeds, other generated index/computation-validation identities, and wider generated closure. Explanation references must not become returned members or count-shape mentions.
- `evidence-needed`: use the existing model-level mandatory-information observation. Separate field-set changes, root-only changes and no contribution with positive controls; document firing cannot settle this service.
- `consumer`: Analyze/Explain need authored shape, literal identity, narrowed bounds and all three result sets. Preserve the distinction between an absent threshold and the literal that narrows to the sentinel.
- `reopen-when`: an adopted analysis consumer needs a specifically excluded rule family. No public general collector contract is implied by the checked subset.
- `route-state`: discovery-required
