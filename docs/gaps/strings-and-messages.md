# String, enumeration and message residuals

[K01–K22](../PLAN.md#remaining-conformance-checklist) selects the required closure work. The [routing table](../PLAN.md#remaining-gap-routing) maps every family and historical D exclusion to its current task or consumer phase. ### SG7 — String, pattern, and custom-field completion

- `state`: residual; D10 pattern/Unicode profiles, D11 custom callbacks/codecs and D23 additional calibration.
- `baseline`: [String expressions](../implementation/strings-and-enumerations.md#cap-string-computation-execution), [patterns/charset](../implementation/strings-and-enumerations.md#cap-pattern-and-charset-admission), [target policy](../implementation/strings-and-enumerations.md#cap-string-target-policy) and [explicit validity](../implementation/validation-messages-and-custom.md#cap-explicit-validity-predicates) own the checked runtime boundaries.
- `host-boundary`: Java patterns outside the built-in compiler and combined-character preparation require explicit host inputs. Conversion-enabled presentation transport and arbitrary registered/shipped validator or codec algorithms remain host-profile responsibilities for K19; [the invocation contract](../sources/domain-ingestion-probes.md#src-checked-string-ingestion-k13) is settled and must not be reopened as an unknown ordering question.
- `representation-boundary`: `elaborateCustomFieldType` and `requireCustomFieldValidator` in [`CustomFieldType.lean`](../../A12Kernel/Semantics/CustomFieldType.lean) refuse an unregistered validator name at checked construction, while the Kernel admits the model and fails the full-check call when a relevant concrete cell reaches the lookup ([spec/06 A.3](../../spec/06-strings-and-enumerations.md#a3-custom-field-type-validation)).
- `host-boundary`: the replay host registers no custom field type from a probe request's `customFieldTypes`, so a request declaring one stays unprepared; registering one needs a Java pattern compiler beyond the builtin closed ASCII profiles ([`+` over a predefined type](../sources/static-admission-and-class-probes.md#src-plus-over-predefined-type), [cross-kind join keys](../sources/key-join-and-parallel-probes.md#src-cross-kind-join-keys)).
- `calibration`: additional partial/category and custom-target combinations outside the frozen K13 matrix. [Explicit validity](../implementation/validation-messages-and-custom.md#cap-explicit-validity-predicates) distinguishes source-grounded Enumeration stored-token/category behavior from measured String behavior; no arbitrary callback correspondence is inferred.
- `reopen-when`: an adopted consumer needs one specific host/profile or a current accepted-case failure requires correction. Pending peer work does not block the accepted ordinary String routes.
- `route-state`: discovery-required

### SG10 — message construction and formal-output integration

- `state`: residual; D07 withholding/multiplicity, D09 providers/locales, D18 structural transport and D22 wider coordinates.
- `baseline`: [Structural references](../implementation/validation-messages-and-custom.md#cap-structural-message-references), [shared pointers](../implementation/validation-messages-and-custom.md#cap-shared-message-pointer), [whole-rule rendering](../implementation/validation-messages-and-custom.md#cap-whole-rule-authoring-and-rendering) and [computed-message partition](../implementation/validation-messages-and-custom.md#cap-computation-message-partition) own current outputs.
- `host-boundary`: the requiredness and Enumeration texts are [measured and produced](../sources/message-parameter-rendering-probes.md#src-field-owned-message-producers). A registered custom validator's text and key are the host's; the replay cannot register the probe's pattern registry without the [host pattern compiler](#gap-sg7), so those captures stay outside the reader route. Locale, display and label provider invocation and catalog default texts are host inputs of the [host-input contract](../IMPLEMENTER-GUIDE.md#host-input-contract).
- `host-boundary`: catalog prose is never produced, so German over-repetition text and additional over-limit index wording need no calibration beyond the [retained texts](../sources/over-repetition-probes.md#src-over-limit-finding-text). Structural inventory and absorption are owned by [over-repetition findings](../IMPLEMENTATION-MAP.md#cap-over-repetition-findings).
- `consumer-gated`: no reader route assembles the whole declaration report from model text; the [declaration report](../implementation/cross-clause.md#cap-declaration-report) and its first-raised producers are exercised member by member. A Govern or Explain consumer that reports a model's full class list needs that route (U01).
- `consumer-gated`: a standalone FlatRuleMessage reference field, raw per-path-part context coordinates and new public structural-message channels need a named consumer. Normalized MessagePointer already serves existing fill-to-fix consumers.
- `consumer-gated`: the generated required finding carries code, severity and type but no text; a consumer renders it through the DM reader's field-message functions. Attaching it to the finding needs the field's label and template on the flat declaration, a core-type change worth making when an Execute consumer emits finding texts from the checked model alone.
- `representation-boundary`: the model-level supported-language classes are not produced, so a model declaring no locale, or two distinct locales sharing one JDK language tag, reads as built where the Kernel draws `MVK_SUPP_LANGUAGES_MISSING` or `MVK_SUPP_LANGUAGES_DUPLICATE` ([spec/01 §1.1](../../spec/01-data-model.md#member-binding)). A model-level class channel beside the declaration report closes it, checked on the `k*` and `b3` rows of the [header locale codes](../sources/model-structure-and-declaration-probes.md#src-header-locale-codes) projection. A bare uppercase pair, a non-ASCII code and the JDK-extended `ja_JP_JP` and `th_TH_TH` stay outside the represented profile, a hint-list locale the parser refuses, whose Kernel reading is unmeasured, is kept as written, and one outside the profile is an error.
- `calibration`: the parsed-locale identity on carriers beyond a rule's message and the hint list's repeat is assumed: an `en-US` hint-list entry with a value past `maxLength` 1 under a declared `en_US`, which Lean now judges, and Enumeration labels split between `en-US` on one value and `en_US` on another, which Lean counts as one locale, would settle it ([map record](../implementation/data-and-core.md#cap-reader-binding-and-literal-readings)).
- `reopen-when`: a concrete output consumer needs one remaining observation; preserve structured identity without copying protected catalog prose.
- `route-state`: discovery-required
