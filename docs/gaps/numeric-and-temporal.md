- `diagnostics`: extractor/component and ValueAsDate wrong-kind refusal classes outside measured carrier pairs, plus keyed DateRange refusal precedence. A class on one extractor is not evidence for every format or computation arm.
- `remaining`: constructed-Date partial validation over recursive/selected components, wider profiles and repeated guard/world calibration beyond the [recursive component boundary](../implementation/temporal.md#cap-recursive-date-components). - `evidence-needed`: temporal distinct-count arithmetic/scheduling compositions, nested-group computation extents and component-omitting computation profiles beyond the [typed distinct-count owner](../implementation/strings-and-enumerations.md#cap-temporal-distinct-count).
