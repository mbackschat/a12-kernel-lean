# Computation residuals

[K01–K22](../PLAN.md#remaining-conformance-checklist) selects the required closure work. The [routing table](../PLAN.md#remaining-gap-routing) maps every family and historical D exclusion to its current task or consumer phase. D labels below describe the former C scope, not a reason to skip a K obligation. The [gap index](../SEMANTICS-GAPS.md) defines residual status; implemented behavior stays in the linked capability owners. Task selection supersedes conditional reopening language for its named acceptance cases.

### SG4 — computation scheduling and state transition

- `state`: residual selected by K08/K09; wider compositions and calibration formerly tagged D14/D20/D24.
- `baseline`: [Checked guards](../implementation/computations.md#cap-computation-conditions), [whole-model plans](../implementation/computations.md#cap-scalar-execution-plans), [mixed plans](../implementation/computations.md#cap-mixed-computation-plan) and [non-Number alternatives](../implementation/repeatable-computations.md#cap-non-number-alternatives) own execution and reader coverage.
- `remaining`: wider guarded operation, indexed/correlated membership and whole-document multi-alternative/repeated-target compositions beyond those owners' admitted matrices. Preserve the distinction between a complete authored plan and a deliberately selected fragment.
- `remaining`: wider parallel Number operand/guard shapes and cross-declaration topology calibration beyond [C14's matrix](../sources/computation-scheduling-probes.md#src-parallel-numeric-operations).
- `remaining`: additional family-at-join and computed-star-source compositions, Now-sourced mixed shifts, and longer mixed producer chains. Source-order tie-breaking between independent steps has no observation in the field-sorted public outcome artifact; do not infer it from result order.
- `remaining`: String row-target first-filled calibration for multi-operand lists, own-level stars and foreign-root stars beyond the [nested-source matrix](../sources/computation-scheduling-probes.md#src-nested-string-first-filled). Use distinct parent values and runtime outcomes to separate row selection.
- `remaining`: cross-carrier first-filled admission and value identity beyond the [typed first-filled boundary](../implementation/strings-and-enumerations.md#cap-first-filled-value), including String/Enumeration and Boolean/Time lists. A differing temporal-format refusal does not establish another kind pair's class.
- `remaining`: non-constant cross-group operation and generated-validation correspondence beyond the [declaring-group measurements](../sources/computation-placement-and-constant-probes.md#src-computation-declaring-group-gate) and current reader locks.
- `remaining`: broader selected-preliminary operation unions and structural-failure reachability beyond the [selected whole-call boundary](../implementation/computations.md#cap-selected-computation-preliminary). Retain conditional laws without inventing an authorable fault witness.
- `remaining`: arbitrary checked-expression operand-path inventories and additional operand-error text/address rendering for the [over-repetition channel](../implementation/repetition-and-paths.md#cap-computation-over-repetition-channel). Local upward-channel calibration remains distinct from retained peer provenance.
- `host-boundary`: whole-model admission refuses incomplete lowering before execution. Arbitrary partial-plan stripping is D14; [below-floor temporal behavior](numeric-and-temporal.md#gap-sg6) is D03.
- `diagnostics`: wider self-read, target placement and group-target/build-tier classification remains with [SG9](paths-and-groups.md#gap-sg9), [SG15](targets-and-derivation.md#gap-sg15) and [SG29](paths-and-groups.md#gap-sg29). Missing diagnostic detail does not imply missing execution.
- `consumer`: Execute/Compile require fresh producer reads, reached poison, clean emptiness, target identity and application to remain distinct. A source-relative delta is never the dependency overlay.
- `reopen-when`: a named consumer needs one remaining composition or a current discriminator contradicts an accepted case. Broader calibration alone does not authorize a new batch.
- `route-state`: discovery-required

### SG18 — addressed computation family calibration

- `state`: evidence residual; D20 additional carrier/profile and producer-chain permutations.
- `baseline`: [Addressed computation owners](../implementation/repeatable-computations.md) and [mixed plan owners](../implementation/computations.md#cap-mixed-computation-plan) retain each carrier's internal and external assurance separately.
- `remaining`: DateFragment copy-versus-render calibration; DateRange cross-spelling/profile calibration; DateTime format/zone/source-shape calibration; world-backed Time components; and FULL Date cross-format/target-policy calibration beyond each owner's retained matrix.
- `remaining`: additional serial Enumeration producer chains, filter-producer kinds and source shapes beyond the existing mixed cascades. A further sibling producer with the same observation domain is not independently a missing mechanism.
- `diagnostics`: addressed target-self-read classes and operand-message rendering beyond the [fixed-target self-read sweep](../sources/diagnostic-class-vocabulary-and-sweeps.md#src-computation-self-read-sweep).
- `host-boundary`: the [custom registration route](../sources/inbound-handbacks.md#inbound-2026-09-22-dispositions) supplies declarative validators. Named shipped-validator algorithms and custom conversions remain [SG7](strings-and-messages.md#gap-sg7), not an absence of every Custom observation route.
- `consumer`: Execute/Compile must distinguish copying a source value from rendering it in the target's format. A same-format fixture cannot calibrate that distinction.
- `reopen-when`: a selected consumer needs an uncalibrated axis; reuse retained evidence before requesting a new observation. [SG12](conformance-evidence.md#gap-sg12) owns correspondence limits and [SG16](#gap-sg16) owns result/application boundaries.
- `route-state`: discovery-required

### SG16 — computation result projection and application

- `state`: residual; D15 explanation/transport certificates and D20 additional carrier calibration.
- `baseline`: [Result/application semantics](../implementation/computations.md#cap-result-and-application), [typed application](../implementation/repeatable-computations.md#cap-typed-result-application) and their family owners distinguish returned partitions, source-relative changes, applied state and later validation.
- `remaining`: wider carrier/profile, cross-group and materialized-topology correspondence beyond those exact application matrices. A generic application function does not externally calibrate every target policy.
- `remaining`: additional multi-operation formal-input unions and later-rule execution beyond the [direct-field](../implementation/computations.md#cap-checked-direct-field-formal-input) and [selected-preliminary](../implementation/computations.md#cap-selected-computation-preliminary) boundaries.
- `host-boundary`: public Kernel result partitions erase clean-clear versus poison state and do not expose per-clear causal attribution. [The audited observation boundary](../sources/inbound-handbacks.md#src-computation-clear-observability) supports same-call dependent-read discriminators; formal operand inventory or missing error messages alone cannot recover that state.
- `host-boundary`: noncanonical String-ingress identity for non-String targets outside the supported Number route must retain original source representation; parsed value or stored spelling alone cannot reconstruct it.
- `consumer-gated`: addressed-index clear attribution, pointer-dialect rendering and source/destination model-compatibility certificates require a named consumer unable to supply the existing same-model precondition.
- `evidence-needed`: separate-destination application beyond current source-grounded controls requires an observation with an independent destination. [computeResults](../sources/cross-layer-routes.md#src-runtime-observation-route) exposes full result partitions and same-source application; it does not supply that parameter.
- `evidence-needed`: object-level over-capacity application, if a consumer requires it. The [serializer boundary](../sources/evaluation-and-application-routes.md#src-applied-document-over-limit-unobservable) cannot settle the applied object state by another JSON request.
- `consumer`: preserve successful unchanged results separately from the change-only projection. Valueless outcome reporting depends on prior target state; the [corrected correlation evidence](../sources/having-filter-probes.md#src-correlated-filter-string-computed-target) does not justify a new absence state based solely on why no value was produced.
- `reopen-when`: an adopted result consumer needs one remaining observation or a reproduced accepted-case mismatch requires correction.
- `route-state`: discovery-required
