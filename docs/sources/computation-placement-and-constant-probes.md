- `revision`: the `dmtool` launcher reports its own build as a12-dmkits `9c86459b352f7989b9dbdae80f71e6dd6cec6066 (clean)`, the pinned measurement checkout; both sibling checkouts read `git status --short` empty before and after. `dmtool` 0.13.0, Kernel `30.8.1` built and runtime, A12 Tools `2025.06-ext5`, catalog verified against `30.8.1`.

- `retained`: **nothing, deliberately.** Two models, each one `model new` plus eight group/field edits with model A adding the Base Year, and 33 one-line computation specs, all named below; the reproduction route is cheaper than the bytes and no hash can be cited for an artifact under an ignored probe path ([`LF138`](../LEAN-FINDINGS.md)).
- `models`: root `Src`, one repeatable `/Src/Rows` (max 20) declaring Number `Base` and `Alt`, DATE `When` (`dd.MM.yyyy`), DATETIME `Stamp` (`yyyy-MM-dd'T'HH:mm:ss`), TIME `Clock` (`HH:mm:ss`), and DATE `Short` (`dd.MM.`). - `prediction`: recorded before the two-model run. If the difference construct shares that shape, the yearless operand is admitted at `DifferenceInYears` only under Base Year, and the clock operand's class *moves* under Base Year because the gate that would have answered is gone.
- `claim`: **both halves hold, and four control rows do not move.** `DifferenceInYears` over the yearless `dd.MM.` operand is admitted in model A and refused `MVK_WRONG_DATE_FORMAT_FOR_OP` in model B; the identical `DifferenceInMonths` row is admitted in both, and `DifferenceInDays` over the same operand and `DifferenceInYears` over the year-bearing `dd.MM.yyyy` are admitted in both. <a id="src-computed-target-gate-is-carrier-invariant"></a>
#### Neither the computed target's admission nor its store can read which carrier produced the value, source-derived locally 2026-09-07

- `route`: kernel source read read-only, no probe of its own. The claim class here is **mechanism**, whose discharge is the branch actually taken rather than an outcome consistent with several; a source read gives that, and is not independent of a probe against the same kernel, so this plus the measured rows below is one discharged mechanism rather than two witnesses.
- `question`: three target certificates and one endpoint certificate were narrowed to an exact declared kind, each retained on the same stated ground — the cross-kind cell was measured for one carrier, and the families sharing the certificate had no row of their own ([`LF116`](../LEAN-FINDINGS.md)). Enumerating carriers would have cost one measurement per family. The cheaper question is whether a carrier is an input to either decision at all.
- `admission-is-the-comparison-gate`: **a computation *is* a comparison condition.** `NormalisierteBerechnungsFormHelper.checkBerechnungsVergleich` requires the condition to be an `IComparisonCondition` under an inequality operator whose `getOperation1()` is a `FieldValue` of the computed field itself, and passes `getOperation2()` on as the computing expression. So a computed target sits in operand-1 position of a real comparison, which is why its refusals are `MVK_INVALID_COMPARE_TO_DATE` — the class `CheckVergleichsBedingungImpl.checkDateType` raises, and the only site in the tree that raises it. That method reads `getOpType(o1Ctx).getDateFormat()`, the same for operand 2, and `OperationResultBaseType.BASE_YEAR`. The target's declared kind is not a reachable input, and a carrier changes only operand 2, whose **result type** is what the gate reads.
- `store-erases-the-carrier`: `CalculationController` has five `handleBerechnetenWert` overloads dispatched on the **value** type, one of which takes `VkDate` for the whole temporal family — there is no TIME-specific one, and no `FormatDefinitionZeit` exists for it to cast to, so all three declared kinds share `FormatDefinitionDatum`. That overload renders through `formatDefinition.getFormat()` — the target's declared format — and re-runs the ordinary field check on the rendered text. The single emitted call site is `CodeGenCalculationAlternative.st`'s `controller.handleBerechnetenWert(<t.calcFunctionCode>, id)`, where the carrier is interpolated as an expression, so by the time the store runs the carrier is erased by construction.
