- `route`: Existing `:adapter:kernelProbe`; the structured CLI atomically converts the default model’s index and key fields to ordinary Enumerations, sets index `sValue`, and authors both rename variants. Kernel model consistency succeeds. Default rows observe both full and partial validation; renamed rows observe full validation.
- `default-matrix`: Singleton absent and present-empty indices acquire the declared `a` pointer in full calls, but remain unknown (`-5`) in partial calls. An explicit `a` resolves on both calls. Zero rows and two empty siblings resolve neither.
- `invalid-separator`: Singleton `Id=z` emits its original formal error on both calls and suppresses dependent rules. The independent `RefUnreached` branch nevertheless points to row 1 in full validation and unknown in partial validation. Its group and lower-star references preserve the same split. Default association therefore does not establish authored value availability.
- `late-population`: The two-parent `default-after-population` row has 25 original entries and selects duplicate `b` row 2 under parent 1; parent 2’s singleton default selects row 1 only on the full call. Physically writing that default in `explicit-in-population` raises the original population to 26, changes parent 1’s winner to row 1, and supplies parent 2’s association on both calls.
- `name-matrix`: Renaming index `Id` to `Key` collides with parent `Key`: duplicate winners at populations 25 and 26 are row 1/row 1. Renaming root `RootKey` to `Key_0` additionally reserves that suffix: winners become row 2/row 2. Each model’s unique-key control still selects the second `b` row. These separate the internal-name effect from key identity and physical traversal.

All pass, including the invalid singleton and both parents of the threshold pair. This checks pointer projection, not independent rule-firing qualification.
- `internal-controls`: [Cache controls](../../A12Kernel/Conformance/MessageCacheOrder.lean) retain full/partial absent, present-empty, explicit, invalid, unrelated-payload, zero/multiple-row, mandatory and over-capacity ancestor controls. #### Legal non-ASCII group names preserve lexical cache-name allocation, measured locally 2026-10-10

- `revision`: Kernel source `cb66e51fa7ab90b650698f861bf670754e2e1e66`; unchanged measurement checkout `6bc5e75337a6b2caea5b563e26d346cf53e163c8`, clean before and after. Both runtime artifacts report Kernel `30.8.1`, dmtool `0.13.0` and clean source. The existing structured `apply` and `:adapter:kernelProbe` routes were reused.
- `matrix`: The selected-reference model's indexed `Rows` group becomes `Gä` or `Gz`; an uninstantiated sibling named `Gz` or `Gä` adds another field named `Id`. Thus short-name allocation depends on lexical full paths while input declaration order keeps the indexed field first. Each model observes populations 25/26 and a unique-key control, on full and whole-scope partial validation; all six rows agree across runtime strategies.
- `observation`: The `Gä` indexed branch selects duplicate row 2 at both populations. The `Gz` indexed branch selects row 2 at 25 and row 1 at 26. Both unique-key controls select row 2. This corroborates `Gz` sorting before `Gä`, yielding internal indexed names `Id_0` and `Id_1` respectively; declaration order and locale collation do not explain the paired threshold result.
- `readback`: Twelve assertions read the actual models and documents through Lean's normal readers, lower `RefUnreached`, derive the full/partial cache and compare the selected Number payload's structural pointer to the retained runtime observation. All pass. This is pointer calibration, not independent rule-firing or consumer qualification. [Reader locks](../../A12Kernel/Reference/Dm/SelectedMessageLocks.lean) retain both lexical directions, capacity thresholds and unique controls on both call phases.
- `static-boundary`: Supplementary-plane and full-width field names, and corresponding group names, were rejected by the terminal Kernel consistency gate with `MVK_PATH_INVALID`; no rejected model was written or executed. `NoMetaModelChecks.check_MVK_PATH_INVALID` distinguishes root groups, child groups and field segments. Its ordinary name alphabets contain no surrogate pairs; admitted German group-name characters remain single UTF-16 units. The generic supplementary-character helper test is therefore not an uncalibrated ordinary runtime profile.
- `limits`: These controls do not establish every declaration-name legality rule, arbitrary Unicode model acceptance, every host implementation, tree-bin ordering or custom admission. The generic UTF-16 helper retains its broader mathematical domain without a corresponding legal-model claim. Remaining host dependence is owned by [MC3](../gaps/paths-and-groups.md#gap-sg29-cache-order).
