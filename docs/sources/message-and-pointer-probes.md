The empty-parameter reading holds only inside the text or at its start: a trailing or lone pair names no parameter and is admitted, and the tokens follow the condition language ([inbound](../SOURCES.md#inbound-2026-09-26n-field-message-gates)).

Dynamic Groovy and generated Java agree under the same explicit label-or-name provider profile.

Payload text, code, and locale do not affect partition membership.
