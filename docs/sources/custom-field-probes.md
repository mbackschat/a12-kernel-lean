These routes prevent deriving whole-call behavior from local value admission alone.
- `route-audit`: The unchanged pinned probe at a12-dmkits `6bc5e75337a6b2caea5b563e26d346cf53e163c8` accepts only declarative pattern/length validators, whose error keys are fixed by `DeclarativeCustomFieldTypes`. Source inspection of the primary checkout finds the same declarative request limitation. No new Kernel runtime claim or harness is introduced.
- `decision`: Preserve the explicit message-cache refusal and do not implement a code-specific availability exception before settling the whole-call matrix. [SPEC-2026-10-10-12](../A12-DMKITS-SPEC-SYNC-LEDGER.md#spec-2026-10-10-12) requests the missing observations.
