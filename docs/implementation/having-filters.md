# Having filter capabilities

Record keys and the `L`/`C`/`X`/`Q` assurance letters are defined once in the [hub's record-key legend](../IMPLEMENTATION-MAP.md#record-key-legend). These records own the leaf, operand and predicate families admitted inside a `Having` filter ([spec/07 §3](../../spec/07-repetition-and-iteration.md#3-the-filter-having-the--correlation-and-aggregation)); [repetition and paths](repetition-and-paths.md) owns stars, correlation and the remaining §9/§10 records.

<a id="cap-having-configured-numeric-sources"></a>
#### Configured numeric sources inside Having

- `boundary`: Explicit numeric Base Year and its four Date components, including both Base-Year range endpoints, compose in the shared numeric tree. They retain the configured year and have no candidate/captured origin or field dependency. An absent configuration is refused; model constants cannot satisfy the filter reference requirement. Both checked numeric routes admit them within their existing placement boundaries.
- `boundary`: `FieldValueAsNumber` accepts direct certified evaluated String, ordinary closed Enumeration and named-category sources in candidate/captured origins on the checked-star route. The complete source certificate rechecks pattern/length or selected token domain, projection and derived scale. The legacy adapter, starred/indexed source operands, custom/table-backed conversion and exact new refusal-class projection remain excluded.
- `owner`: [Numeric conversion semantics](../../A12Kernel/Semantics/NumericConversion.lean) now own the existing decimal parser, resolved source and shared observation projection; [NumericSource](../../A12Kernel/Elaboration/NumericSource.lean) retains model certification. [Base-Year semantics](../../A12Kernel/Semantics/BaseYearDateSource.lean) retain floor-free calendar labels. [Correlation](../../A12Kernel/Semantics/CorrelationInputs.lean) supplies origins and phase reads without a second conversion or calendar account.
- `assurance`: [Reader locks](../../A12Kernel/Reference/Dm/HavingComparisonLocks.lean) cover configured/missing/constant-only bodies, every Base-Year component/source form, arithmetic, String and stored/category decimal conversion, wrong domains/bounds/syntax, captured producer freshness and token-carrier pointers. [Core locks](../../A12Kernel/Conformance/CorrelatedComparisonInputs.lean) reject forged scales and unavailable scopes, preserve symmetric empty zero, poison and structural-error ordering, and distinguish originless model constants. [Legacy locks](../../A12Kernel/Conformance/CorrelationElaboration.lean) check Base Year alongside both field origins. Certificate-bypass and structural-error substitution mutants fail; ordinary conversion laws retain their unchanged statements over the shared observation.
- `consumer`: Execute retains amount, projected token domain, configured year and phase effects; Analyze/Transform retain source syntax, scale and actual row dependencies. This is same-context adequacy, not independent qualification. New filtered runtime compositions remain external evidence pending; public protocol and broader filtered-carrier pointer support do not expand. Both Having cells remain partial.
