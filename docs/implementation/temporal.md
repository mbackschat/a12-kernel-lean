#### Placed-temporal-cell coherence property

- `state`: implemented as an opt-in property, `CheckedDocument.temporallyCoherent`, reporting whether every placed cell whose declaration a Date or DateTime input classifier owns agrees with the value that classifier derives from the cell's own stored text. Deliberately **not** a construction gate.
