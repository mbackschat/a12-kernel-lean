# Analyze consumer lab

- `status`: green for bounded presence reachability, checked scalar numeric-table cycle analysis, and generated-computation phase-alias safety; amber for broader family-neutral graph reconstruction
- `contract`: a checked artifact produces facts, witnesses, or explicit insufficient information under a named query and bound.
- `authority`: the proof-bearing [presence contradiction analyzer](../../A12Kernel/Elaboration/Flat/PresenceContradiction.lean), its [never-fires theorem](../../A12Kernel/Proofs/FlatPresenceContradiction.lean), checked flat-condition evaluation, and the checked numeric [operation/table dependency projections](../../A12Kernel/Elaboration/NumericComputation/FormalInput.lean) with their [exactness theorems](../../A12Kernel/Proofs/NumericComputationFormalInput.lean).
- `solver`: installed Z3 CLI through canonical SMT-LIB; solver output is never semantic authority.

## First probe

Encode bounded presence reachability for two exact flat conjunctions. The same-field `FieldFilled(A) And FieldNotFilled(A)` query should be solver-UNSAT and the different-field `FieldFilled(A) And FieldNotFilled(B)` query should be SAT. Decode the SAT assignment into an A12 presence witness and replay it through Lean.

Lean acceptance separates the two result directions. Replayed SAT is a verified witness. Raw Z3 UNSAT is only `solverReportedUnsatWithinBounds` unless the existing Lean contradiction certificate independently closes that exact shape. Wrong accounts are authored-error polarity reversal, absence/formal collapse, different-field aliasing, and presenting raw UNSAT as certified.

## Computation-cycle probe

Analyze a disposable language-neutral computation artifact as a target-field dependency graph. Detect a direct two-target cycle and an indirect three-target cycle, recover a dependency order for an acyclic chain even when its supplied order is reversed, and keep `CurrentRepetition(group)` structural rather than expanding it into dependencies on computed descendants. Every cycle path must carry its computation rule and read-site labels; every accepted acyclic order must satisfy all extracted edges.

This remains an Analyze probe rather than another consumer category or a public graph surface. It covers computation value dependencies only. Validation rules read a document snapshot and emit messages, so mutual validation references are not computation feedback cycles. Wrong accounts are pair-only detection, supplied-order rejection in place of cycle analysis, structural-group expansion, omitted precondition reads, and unchecked cycle paths.

The checked scalar numeric-table profile derives its cycle graph from each table's raw dependency inventory before the full-call formal-input projection removes every computed target. It traverses all alternatives and expands a fixed `NumberOfFilledGroups` operand to its declared fields. The full-call noncomputed input set remains a separate result and is never reused as the cycle graph.

## Generated-phase alias probe

Analyze whether one scalar-target generated computation may alias its immutable execution source with the later applied-destination validation snapshot. The bounded artifact contains one unfiltered repeatable Number sum and one correlated repeatable Number `FirstFilledValue`, with source and destination rows chosen so both the result and, for `FirstFilledValue`, the selected row differ between phases. The consumer must separate dependency roles, source execution, source-relative action classification, destination application, target-filled gating, and destination recomputation, then produce a concrete counterexample to snapshot aliasing.

The natural handover deliberately tests shipment sufficiency as well as semantic reconstruction. Its first version omitted Number signedness, Number scale, and the repeatable-group bound, so its mechanically correct result remained amber because aggregate mismatch polarity required an unstated assumption. The corrected artifact supplies those declaration facts explicitly and leaves the consumer to derive the phase and polarity semantics. General scheduling, repeatable targets, materialized topology, pointer rendering, and Kernel correspondence remain explicit insufficient-information results.
