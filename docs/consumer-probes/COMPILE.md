# Compile consumer lab

- `status`: green
- `contract`: a checked A12 artifact becomes an executable specialized plan or target program under a named refinement relation.
- `authority`: the shared checked condition-tree evaluator and its [three-valued control-flow capability](../IMPLEMENTATION-MAP.md#cap-shared-condition-tree-control-flow), plus the [checked direct-field formal-input inventory](../IMPLEMENTATION-MAP.md#cap-checked-direct-field-formal-input), its selected index preliminary and parallel Number and indexed DateRange whole-call consumers, [exact-address Number `FirstFilledValue`](../IMPLEMENTATION-MAP.md#cap-exact-address-repeatable-number-firstfilledvalue-result-application), and [generated computation validation](../IMPLEMENTATION-MAP.md#cap-generated-computation-validation).
- `handover`: the logic/formal-error, repetition-order, and computation-order clauses, one finite admitted source condition or generated numeric table, and the bounded selected-preliminary artifacts for each named whole-call, conversion, or prepared execution/application/validation plan. A generated-validation artifact must carry its declaration-owned table name rather than ask the compiler to reconstruct the error code.

## First probe

Compile one bounded source-first conjunction over the finite `value`, `empty`, and `formal` observation domain into a standalone specialized decision function. Exhaustively compare every admitted input pair against the Lean-owned truth, poison, and read-order projection.

The finite domain makes exhaustive refinement meaningful for this exact plan. It does not prove a general compiler. Wrong accounts are ordinary Boolean collapse, eager right evaluation, formal-to-false conversion, and reordered reads.

## Generated-table probe

Compile one admitted two-alternative generated numeric table into a standalone specialized selector and static input query. The table has a common `FieldFilled` guard, distinct row-local `FieldFilled` and `FieldNotFilled` guards, and operations with distinct dependencies. Exhaustively compare the specialized selector with an independently structured generic evaluator over the 27 `empty`/`value`/`malformed` assignments, then reconcile every selection outcome and the complete target-excluding input projection with Lean.

This refinement covers common-before-local evaluation, first-match selection, reached poison, and static all-alternatives dependency projection for this table. It does not execute the numeric operations or establish a general compiler, scheduler, generated-validation runtime, protocol, or shipment. Wrong accounts are common-guard omission, local-before-common evaluation, later-alternative omission, Boolean complement collapse, poison-to-false conversion, runtime-selected dependencies, retained computed targets, and artifact traversal order.

## Selected-preliminary whole-call probe

Compile one generic selected-index preparation artifact plus isolated parallel Number and field-key indexed DateRange whole-call artifacts into specialized executable plans. The plans must derive declaration-ordered role unions, exclude computed targets, stage full-call Enumeration index defaults, limit mandatory and uniqueness rules to selected noncomputed indexes, retain cached and generated findings independently of runtime reachability, and preserve the existing family result channels. A literal-key DateRange control must contribute no selector field.

Lean acceptance checks the exact generic prepared inventory, both staged defaults, the parallel ordinary/index split and two exact clears, the DateRange endpoint/selector/index split and scalar clear, and the literal-key negative dependency control. Wrong accounts are direct-fields-only collection, computed-target preliminary checking, selected-only default staging, all-index preliminary checking, selector omission, literal-as-field dependencies, shared-index omission, and moving eager findings into computed errors or aborting execution. Scheduling, rendered messages, document application, later validation, literal-key execution, protocol, shipment, and Kernel correspondence remain excluded.

## Selected conversion-composition probe

Compile three frozen selected-preliminary artifacts into specialized executable plans: an Enumeration default crossing two completed Enumeration overlays, an Enumeration default crossing `FieldValueAsNumber` and a filtered final Enumeration read, and a fixed `CurrentRepetition` Number-to-String-to-Number chain. Compare each plan with a structurally independent generic artifact evaluator over a finite variant matrix.

Lean acceptance fixes the three named artifact outputs and a missing-required separator. Generated `required` findings remain eager-only, while duplicate-index findings poison the selected source read; a poisoned String result retains that cause internally and only the downstream Number dependency becomes cause-blind. The finite variants separate wrong compiler accounts but do not claim additional Kernel correspondence or a general compiler. Scheduling, application, later validation, protocol, shipment, and compatibility remain excluded.

## Addressed Number whole-call probe

Compile one checked two-star Number `FirstFilledValue` artifact into a specialized plan while a structurally independent generic evaluator interprets the same artifact. Both must keep ordered source and computed-target roles separate, prepare every selected noncomputed source eagerly, scan each parent-local source extent in ascending repetition-coordinate order, retain physical target encounter order, stop runtime reads at the first value or poison, apply target policy only after selection, and project results relative to the immutable source target state.

The exact denominator is 13 distinct natural cases and 65 target executions. One source-row-storage permutation is a negative control because source extents use ascending coordinates rather than storage order. Wrong accounts are first-source-only or target-inclusive formal plans, cached-only preparation, eager-finding abort, immutable reads, global or row-zipped scans, eager suffix reads, no-value exhaustion, fallback after target rejection, raw-to-typed message copying, and destination-relative change classification. The probe qualifies only bounded compilation feasibility: all implementation and checking code is disposable and capability-local, and its volume is not evidence for a compact maintained compiler.

## Prepared phase-pipeline probe

Compile one prepared generated Number table and one prepared DateRange endpoint-component artifact into specialized plans while a structurally independent generic evaluator interprets the same artifacts. The generated table must preserve the complete selected noncomputed field set while deriving the narrower index-source subset from declaration roles, keep duplicate-index findings separate from runtime poison and typed messages, execute either a direct source or prepared repeatable aggregate, classify its source-relative result, apply it to a separate destination, and run later validation over that applied destination. The DateRange control must clear both affected targets after duplicate-index poison without application or validation.

Lean acceptance fixes the two generated alternatives, the DateRange duplicate route, complete plan roles, exact findings, result partitions, retained clear state, and later validation outcomes. Wrong accounts drop later dependencies, include the computed target, truncate only one duplicate finding, abort on eager findings, read immutable sources, spread poison globally, copy findings into messages, validate in the wrong phase or against the wrong world, erase a cleared target, collapse DateRange poison to zero, omit the selected source, or merge the phase results into one status. This remains a three-case compiler feasibility result, not general scheduling, compilation, document transport, Kernel correspondence, protocol, or shipment.
