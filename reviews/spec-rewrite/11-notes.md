## Behavioural decisions

1. **The keyed-guard leaf list is closed** (ch11-1, spec/14 G). Old 11:50: "Negative presence predicates and arbitrary comparisons supply no such guard." New A.10: those "supply no guard, and neither does any other leaf outside the first three classes (source reading)", so value-list, uniqueness, pattern, validity, overlap and `CustomCondition` leaves are `none`. Lean: `ValidationCondition.keyedMessageLeafGuard` and `keyedMessageGroupGuarded`, `A12Kernel/Elaboration/MessageGroupGuard.lean`. Unmeasured beyond the keyed `GroupFilled` admission (row `a04`) and the unguarded refusal (row `b02`).
2. **Group-parameter admission order and the index-reference mode** (ch11-2). Old 11:26: "The named group must be **available**, and two arms make it so: the rule's own group and its ancestors at any depth, and any group holding … something the condition reads." Old 11:43: "This distinction applies both to the index terminal's reference-mode check and to unkeyed group-parameter availability". New A.10 stage 6: an unkeyed parameter on an indexed repeatable group needs an authored non-selection reference inside the group, else only the ancestor arm admits it and only when the condition selects no group by key; stage 7 `ITER_PARAM_WITH_STARREFERENCE` for a repeatable group whose repeatability exceeds one. Lean: `checkMessageGroup`, `checkMessageGroupMode`, `admitMessageGroup`, `resolveMessageGroup` (`A12Kernel/Elaboration/ValidationMessageAuthoring.lean`); `unkeyedGroupReferenced?`, `anySelectedGroupReferenced?`, `nonWildcardGroupReferenced?`, `selectedGroupReferenced?` (`A12Kernel/Elaboration/MessageAuthoringContext.lean`). Stage 7's existential rule is measured (`model-structure-and-declaration-probes.md#src-error-text-row-parameter`, existential, ordered after `INVALID_GROUP`); stage 6's keyed half is measured (Cases2 rows, `h02`); the unkeyed half is marked source reading; decision 14 narrows stage 7's measured scope.
3. **Name-position keyed parameters need no presence guard** (ch11-1). Old 11:48/11:50 are silent on the name position. New A.7: no guard, cited to rows `k01`–`k11` beside `FieldNotFilled(/Kp/Rows/Base For "k1")`. Lean agrees: `ValidationMessageCondition.messageKeyedMember?` (`MessageAuthoringContext.lean`) asks no guard. Measured, so stated without an unmeasured marker.
4. **The value suffix's two gates are ordered** (A.6). Old 11:13 states both gates and no order. New: the star gate answers first, marked source reading, unmeasured. Lean: `valueAccessRefusal`, `A12Kernel/Elaboration/ErrorTextParameterAddressing.lean`.
5. **Two index-terminal additions** (A.9). (a) Old 11:41: "a `For "k"`-keyed one and a **starred** one each draw `INVALID_INDEX_FIELD_REP_ITER`" (silent beside a plain read). New: it does so even beside a plain read of the same index, unmeasured. Lean: `messageIndexReferenceRefusal` (`IndexMessageAuthoring.lean`) and `namedRuleDiagnostic?` (`ValidationMessageDiagnostic.lean`).
6. **The key's group is the nearest indexed one** (A.7). Old 11:23: "A keyed **field** read covers that field and **the group's declared index field**" (which group unstated for a deeper field). New: "the field's nearest enclosing repeatable group that declares an index field, measured where the groups between are unindexed". Lean: `FlatModel.semanticIndexGroupForPath?` (`A12Kernel/Elaboration/SemanticIndex.lean`, innermost indexed level).
7. **"Pure render step" against the keyed-row fault.** Old 11:3: "Interpolation is a pure render step over an already-fired message". Old 11:33: "A key that selects no row faults a value parameter only: the rule's evaluation fails as a runtime failure does". Side taken: 11:33 (measured, rows `RMiss`, `RMissK`); the intro and the A.11 note now name it as the one exception. No Lean def needed; the chapter's own measurement decides.
8. **S-value coincidence scoped** (negative existential 11:41). Old: "that distinction is unreachable, because a non-member S-value is refused `MVK_S_VALUE_INVALID` … so the two readings agree on every legal model." New: they agree on a non-member S-value (measured); a blank S-value is unmeasured. Old 11:34: "the per-segment quote escape renders exactly as the bare spelling does, so quoting is transparent at runtime as well as at admission". Side taken: 11:34 (measured render); the caveat is dropped and A.3/A.10 state transparency. Decided by the chapter's own measurement.
