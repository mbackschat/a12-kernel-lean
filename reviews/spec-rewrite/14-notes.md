# spec/14 operator reference — change notes

Drafts: `14-new.md` (new chapter), `02-new14.md` and `10-new14.md` (full revised spec/02 and spec/10, built on the committed `217df823` versions). The chapter has 115 operator rows in 16 family tables and six columns (V, C, E, P, F, X), each with a class vocabulary that links its defining section; each column's measured scope is one sentence linking the clause that owns it. No builds were run, no repository file was edited, and the prose guard was not run (it reads `../a12-kernel/`). spec/14 carries no `Sources:` line: every measured-scope sentence links the owning chapter section, which carries its own. Static `n/a` follows one policy: a cell is `n/a` only where a chapter states the operator cannot take that input, cited in the column section; a refusal found only in Lean leaves the cell `not stated`, with the Lean def under Not stated.
